# Data

| Folder | Versioned | Contents |
|--------|-----------|----------|
| `sample_flight_logs/` | yes | A few representative flight logs (CSV), used by `ml/pinn/` |
| `logs/` | no | All raw logs downloaded by `tools/download_logs.py` |
| `plots/` | no | Figures generated by `tools/plot_logs.py` |

Only add a log to `sample_flight_logs/` if it is small and useful to others
(it stays in the git history forever).

## Log columns

`time_us, dt` - timestamp (µs) and loop period (s)
`gyroRoll, gyroPitch, gyroYaw` - filtered body rates
`rxThrottle, desiredRollRate, desiredPitchRate, desiredYawRate` - pilot commands
`armSwitch, frameLost, failsafe` - receiver state
`pRoll, iRoll, dRoll, ...` - P, I, D contributions per axis
`roll_coeff_p, ...` - PID gains in use
